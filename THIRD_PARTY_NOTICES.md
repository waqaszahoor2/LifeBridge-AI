# Third-party notices and attribution checklist

LifeBridge AI includes integration code but does not transfer ownership of provider data or branding.

- **OpenStreetMap:** include OpenStreetMap contributors attribution wherever map/data results are shown; review the ODbL and tile/service usage policies.
- **O*NET:** include the attribution required by the O*NET Database licence and identify modifications.
- **NASA EONET, GDACS, ReliefWeb, Open-Meteo, USAJOBS and Adzuna:** follow current provider terms, rate limits, attribution and redistribution rules.
- **Firebase:** comply with Firebase/Google terms and privacy disclosures.
- **Scholarship providers:** reproduce only concise metadata and link to the original programme page; do not imply endorsement.
- **Open-source packages:** package licences remain in effect. Generate a dependency bill of materials before production release.

The source registry is in `research/source_registry.csv`. Terms can change, so review them again at deployment time.
