# Dataset licence notes

The bundled synthetic CSV files are part of this project package. External datasets are not automatically covered by the repository licence.

Before adding external data, record:

- publisher and original URL;
- licence/terms version and review date;
- permitted research, redistribution and commercial use;
- attribution text;
- personal/sensitive data handling;
- deletion or expiry obligations;
- whether derived models may be redistributed.

Official provider APIs should normally be queried at runtime or through controlled ingestion rather than copied into a public repository.
