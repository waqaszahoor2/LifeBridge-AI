# Model card — skill/role index

## Purpose

TF-IDF role index for demonstrating CV skill extraction and explainable role matching.

## Limitations

The bundled skill taxonomy is small and synthetic. It does not represent global job markets, seniority, credential requirements, language differences, labour law or employer selection.

## Evaluation

For research, compare recommendations against a reviewed occupation taxonomy and vacancy data using Precision@K, Recall@K, NDCG, subgroup analysis and human relevance judgements.
