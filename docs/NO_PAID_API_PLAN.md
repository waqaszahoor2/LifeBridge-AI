# No-Mandatory-Paid-API Plan

The academic prototype works with synthetic data plus NASA EONET, GDACS, Open-Meteo and OpenStreetMap. No paid generative-AI service is required.

Optional accounts may be needed for USAJOBS, ReliefWeb, Firebase and Adzuna. These credentials are not embedded in the source code.

Costs may still arise from hosting, domain registration, storage, database capacity, commercial traffic or paid provider quotas. “No paid API key” does not mean unlimited zero-cost production operation.
