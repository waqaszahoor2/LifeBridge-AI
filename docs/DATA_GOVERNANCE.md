# Data Governance

- Collect only fields needed to show and rank a feed post.
- Keep source content attribution and original URLs.
- Store `published_at`, `collected_at`, `last_checked_at`, `updated_at` and `expires_at` separately.
- Label synthetic records `demo` and never mix them silently with field evidence.
- Do not collect passwords, OTPs, full payment-card data or unrelated private conversations.
- Apply retention limits to uploaded CVs, screenshots and QR images.
- Provide delete/export controls before real user testing.
- Record source licence, collection method, last review date and restrictions.
- Do not train on user submissions without explicit consent.
- Evaluate performance separately by language, country and user group.
