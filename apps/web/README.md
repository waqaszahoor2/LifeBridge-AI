# LifeBridge Web

Responsive Next.js client with feed, recommendations, SkillBridge, AccessLink, DisasterLink, VerifyLink, ServiceLink, decision graph, system/light/dark themes and exact source timestamps.

```bash
npm install
cp .env.example .env.local
npm run dev
```

Vercel Root Directory: `apps/web`. Set `NEXT_PUBLIC_API_BASE_URL` to the deployed FastAPI origin; never place private API keys in this application.
